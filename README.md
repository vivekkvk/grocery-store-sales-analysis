# 🛒 Grocery Store Sales Analysis

## 📌 Overview
Analyzed 100,000+ grocery store transactions across 7 relational tables 
using MySQL and Python to uncover sales trends, top products, and customer insights.

## 🛠️ Tools Used
- Python 3.14
- MySQL — data storage and SQL queries
- Pandas — data cleaning and analysis
- Matplotlib — data visualization
- Jupyter Notebook
- VS Code

## 📊 Key Findings
- Identified top performing product categories driving majority of revenue
- Analyzed city-wise sales across 96 cities and 206 countries
- Discovered discount impact on total revenue
- Identified top performing employees by sales revenue

## 🚀 How to Run
1. Clone the repository:
   git clone https://github.com/vivekkvk/grocery-store-sales-analysis.git
2. Install required libraries:
   pip install pandas matplotlib mysql-connector-python sqlalchemy pymysql python-dotenv
3. Set up .env file with your MySQL credentials:
   MYSQL_USER=root
   MYSQL_PASSWORD=yourpassword
4. Open the notebook:
   jupyter notebook groceyanls.ipynb
5. Run all cells from top to bottom
